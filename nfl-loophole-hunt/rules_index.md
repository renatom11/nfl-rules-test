# Rules Index — 2026 NFL Official Playing Rules

Source: *2026 Official Playing Rules of the National Football League* (91 pp., PDF metadata dated 2026-07-14; SHA-256 in `sources.md`). Citations use Rule-Section-Article (e.g. 6-1-5), the rulebook's own notation. The full text is split by rule in `rules_text/rule_NN.md`.

The **Official Casebook**, which holds the Approved Rulings (A.R.s) that 3-1 refers to, is **not publicly available** (see `sources.md`). Every "casebook" check in this project therefore means checking the Notes, Exceptions and Supplemental Notes printed inside the rulebook itself.

**2026 changes** (rulebook cover page): 6-1-3 (receiving-team setup-zone alignment), 6-1-5 (touchback after a kickoff from the 50 goes to the 20), 6-1-6 (onside kick may be declared **at any time**), 19-2 (League office may consult on disqualifications even if not called on the field).

## Rule-by-rule summary

| Rule | Section | One-line summary |
|---|---|---|
| **1 The Field** | 1 | 120×53⅓-yd field; goal lines 10 yds from end lines; 6-ft white border; coaches' yellow line. |
| | 2 | Yard lines every 5 yds; hash marks 70'9" from sidelines; goal line is 8 in. wide and lies *in* the end zone; pylons. |
| | 3 | Crossbar 10 ft high, 18'6" wide; uprights 35 ft above crossbar. |
| | 4–5 | Chain/ball crew identification; home club supplies approved sideline markers. |
| **2 The Ball** | 1–2 | Wilson ball specs; Referee sole judge; 12 primary + 12 backup + 3 "K" balls per team; center may request a playable ball on wet field. |
| **3 Definitions** | 1–42 | Definitions of every term (see "Key definitions" below). |
| **4 Game Timing** | 1 | 4 × 15-min periods; 2-min intermissions; 13-min halftime; game officials may correct the clock only before the next legal snap or kick. |
| | 2 | Coin toss (visitor calls; winner may defer), choice of receive/kick or goal; change goals after 1st & 3rd periods. |
| | 3 | When the clock starts: free kick (legal touch in field of play), scrimmage down (snap, or ready-for-play exceptions incl. runner OOB, fouls, 10-sec runoffs); **(e)(1)–(5) fouls restart on the snap after 2MW of 1st half, inside last 5:00 of 2nd half, and for any offensive pre-snap foul in the 4th period/reg-season OT**. |
| | 4 | When the clock stops (kick downs, OOB, incomplete, fouls, change of possession, 2MW, etc.). |
| | 5 | Charged timeouts (3 per half, 2 per reg-season OT); consecutive-timeout and excess-timeout penalties; freeze-the-kicker rule; injury timeouts before/after 2MW; 10-sec runoffs; Referee's timeout. |
| | 6 | 40/25-second play clocks and resets; delay-of-game acts, incl. defensive feints and spiking after the down. |
| | 7 | **Actions that conserve time after the two-minute warning** (fouls stopping the clock, grounding, illegal pass, backward pass OOB, spike, illegal bat/kick OOB) → 5 yds + 10-sec runoff vs offense; last-40-seconds defensive rule; runoffs after reversals. |
| | 8 | Period extends to end of down; untimed down after accepted defensive foul; no extension for offensive fouls (with 5 exceptions); Try after TD; fair catch kick; double fouls. |
| **5 Players, Subs, Equipment** | 1 | 11 players; >11 in formation (A: >3 s; B: snap imminent) = dead-ball foul; designated kickoff holder may be a 12th person; jersey numbering by position. |
| | 2 | Substitution rules: substitute must reach inside the numbers; no simulated substitutions; defense must be allowed to match subs before the 2MW (and on 4th-down punts all game). |
| | 3 | Reporting change of eligibility (eligible number reporting ineligible must stay in 5-man core); when reported players may revert; helmet radio rules. |
| | 4 | Uniform and equipment standards; penalties for violations. |
| **6 Free Kicks** | 1 | Kickoff / safety kick / onside kick; tee & designated holder; restraining lines (kicker own 35, team B40, receivers B35), setup zone (B35–B30), landing zone (B20–goal); formation rules; catch/recovery; touchbacks (20 or 35; 20 if kicked from the 50); **onside kick any time, if declared**, with its own formation and 15-yd penalty if untouched beyond setup zone. |
| | 2 | Blocking restrictions on kickoffs and onsides (no double-teams outside setup zone, no wedges); running into free kicker; kick OOB / short of landing zone → B ball 25 yds from kick spot; illegal touching; voluntarily OOB. |
| | 3 | Free-kick foul enforcement (previous spot & re-kick, or dead-ball spot if B keeps ball). |
| **7 Ball in Play, Dead Ball, Scrimmage** | 1 | Ball becomes live when legally snapped/kicked. |
| | 2 | Every way the ball becomes dead (a)–(s), incl. kneel/simulated kneel, slide, ball at rest, erroneous whistle, ball hitting video board, helmet off. |
| | 3 | When A or B gets a new series. |
| | 4 | False start, encroachment, NZI, offside, one-second set, shifts, motion. |
| | 5 | Offensive formation: ≥7 on line, eligible ends, numbering/reporting, nobody "neither on nor off" except one player directly behind snapper. |
| | 6 | Snap rules (any lineman may snap; snap that hits the ground may be recovered by anyone). |
| **8 Passes, Fumbles** | 1 | Forward pass definition, one legal forward pass from behind line, illegal passes, catch process, eligibility, illegal touching (5 yds, no loss of down for ineligible). |
| | 2 | Intentional grounding (outside-pocket exception; T-formation QB spike). |
| | 3 | Ineligible downfield (1-yard limit) on legal forward pass plays. |
| | 4 | Illegal contact (5-yd chuck zone) — only while snap-receiver is in pocket with ball; ends on handoff/pitch/pass; relaxed vs punt formation. |
| | 5 | Pass interference (>1 yd beyond LOS; offensive from snap; relaxed vs gunners in punt formation "before the ball is kicked"); DPI spot foul / 1-yard line. |
| | 6 | Pass-play enforcement and exceptions. |
| | 7 | Backward passes (OOB after 2MW = time-conserving), fumbles, forward fumble OOB, end-zone fumbles, forward handoffs, 4th-down/2MW/Try fumble rules (only fumbler may advance). |
| **9 Scrimmage Kick** | 1 | Kick from on/behind line; second kick legal if ball hasn't crossed and returned; who may go downfield; defensive formation limits vs punt/FG; blocking during kicks; voluntarily OOB. |
| | 2 | First touching (violation), out-of-bounds kicking players, blocked-into-kick. |
| | 3 | Recoveries behind/beyond the line; kickers' recovery beyond line dead; simultaneous → receivers. |
| | 4 | Kick into end zone (dead, touchback), goal-post rules, kick lying dead in field. |
| | 5 | Enforcement incl. post-possession fouls. |
| **10 Opportunity to Catch, Fair Catch** | 1 | Kick-catch interference (15 yds from spot, snap). |
| | 2 | Fair catch definition/signals (valid/invalid), muffs, illegal block after signal, restrictions, ball put in play by snap or **fair catch kick**, end-of-period extension. |
| **11 Scoring** | 1 | Values; forfeit = 2-0. |
| | 2 | Touchdown (plane, pylon, loose ball in end zone, palpably unfair act). |
| | 3 | Try: either team can score; 15-yd line for kick, 2-yd line for run/pass; 1-pt safety; foul enforcement incl. "other Try spot". |
| | 4 | Field goal requirements; missed FG spot (B20 or spot of kick); fair catch kick uses **onside free-kick formation**; no tees; no foreign articles. |
| | 5 | Safety (incl. momentum exception); safety kick from 20 (punt allowed). |
| | 6 | Touchback definition and next spot (20; 35/20 for free kicks). |
| **12 Player Conduct** | 1 | Legal/illegal blocks, holding, assisting runner (pulling only), defensive use of hands. |
| | 2 | Personal fouls: clipping, peel-back, below-waist, chop, crackback, blindside, unnecessary roughness, defenseless players, helmet, roughing passer/kicker/holder, striking, facemask, horse-collar, hip-drop. |
| | 3 | Unsportsmanlike conduct list (a)–(v); repeated fouls to prevent score; **multiple** fouls to manipulate clock; palpably unfair act. |
| | 4 | Automatic DQ for two taunting/abusive/punch fouls. |
| | 5 | Illegal bat and illegal kick. |
| **13 Non-Player Conduct** | 1 | Bench conduct, credentials, restricted areas, sideline movement; non-player palpably unfair act. |
| **14 Penalty Enforcement** | 1 | Declining penalties/yardage; number of down after penalties; **every Team B foul = first down except listed**; multiple fouls. |
| | 2 | Half-distance; fouls behind goal line; fouls during scores (take points off board); personal-foul dead-ball-spot option. |
| | 3 | Spots of enforcement; basic spot; three-and-one. |
| | 4 | Enforcement before/at snap, during runs, after change of possession, end-zone cases, passing plays, fumbles, free kicks, scrimmage kicks, dead-ball and between-downs fouls. |
| | 5 | Double fouls: offset/replay, 5-vs-15, clean hands. |
| **15 Instant Replay** | 1–9 | Challenges (need timeout, 2 + 1), booth reviews (after 2MW, OT, scores, turnovers), reviewable/non-reviewable items, clock resets and 10-sec runoffs, foul nullification, officiating-department assistance. |
| **16 Overtime** | 1 | Modified sudden death; both teams get an "opportunity to possess" (a kickoff counts; kicking-team recovery counts as receiving team's opportunity); 10-min reg-season OT with 2 timeouts; postseason 15-min periods, 3 timeouts per "half". |
| **17 Emergencies, Unfair Acts** | 1–2 | Field control, called/interrupted games; Commissioner's power over "extraordinarily unfair" acts "outside the accepted tactics". |
| **18 Captains** | 1 | Up to six captains; one declares choices. |
| **19 Officials** | 1–2 | Seven officials; Referee final authority; League may order disqualifications. |
| Appendix | — | Penalty summary, signals, foul codes, index. (Not normative but useful for mismatches.) |
